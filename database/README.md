# Database

This project uses **SQLite3** as the backend database.

## Tables

### 1. users

Stores user account information.

| Column | Type |
|--------|------|
| id | INTEGER |
| name | TEXT |
| email | TEXT |
| age | INTEGER |
| password | TEXT |
| created_at | DATETIME |

---

### 2. predictions

Stores all emotion prediction results generated by the facial and audio emotion recognition models.

| Column | Type |
|--------|------|
| id | INTEGER |
| user_id | INTEGER |
| timestamp | DATETIME |
| file_type | TEXT |
| filename | TEXT |
| emotion | TEXT |
| confidence | REAL |

---

### 3. activities

Stores learning activities completed by users based on detected emotions.

| Column | Type |
|--------|------|
| id | INTEGER |
| user_id | INTEGER |
| emotion | TEXT |
| activity_name | TEXT |
| timestamp | DATETIME |

---

## Database Creation

The database is automatically created when the Flask backend starts for the first time by executing the `create_database()` function located in `backend/database.py`.

## Sample Data

Run `seed.sql` to populate the database with demo records for testing.
